# Test2 folder scripts

This file lists the Python scripts in this folder and gives a short description of what each one does.

- **check_compatible_samples.py**: Inspect sample pairs or groups and determine whether they are compatible for merging, comparison, or model training.
- **check_for_j.py**: Find and report samples or labels that include the letter "J" or special cases related to the sign/letter "J" in the dataset.
- **compare_samples.py**: Compare two or more samples for similarity, differences, or alignment in landmarks and timing.
- **compose_samples.py**: Combine two or more samples into a composed output sequence or merged representation.
- **find_oriented_samples.py**: Search for samples that include orientation information or oriented hand poses.
- **get_sample_info.py**: Retrieve metadata and statistics for a specific sample, such as frame count, labels, or landmark coverage.
- **inspect_labels.py**: Inspect and summarize label data across samples, including label distributions and anomalies.
- **renderer.py**: Render samples or sequences to images and videos, likely using a shared rendering pipeline.
- **tempCodeRunnerFile.py**: Temporary file created by the editor for ad-hoc scripting; not part of the main toolset.
- **test_normalization.py**: Test or validate sample normalization routines, including landmark normalization and scaling.
- **test_transitions.py**: Test transition logic or transition detection between gesture segments.
